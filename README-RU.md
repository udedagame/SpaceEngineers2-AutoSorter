# AutoSorter 0.2.4 для Space Engineers 2

[English](README.md)

Исправление выбора складов и выгрузки пристыкованных кораблей. Сборка и автоматические проверки выполнены; переносы в живом игровом мире ещё требуют проверки.

## Правила сортировки

Переименование не требуется. Контейнер только с рудой принимает руду, только со слитками/материалами — материалы, только с компонентами — компоненты. Смесь категорий служит источником. Инструменты и оружие не перемещаются и не назначают склад.

Сначала используются доступные склады нужной категории, среди них — более вместительные. Заполненные по массе склады пропускаются без расходования попытки переноса. Если подходящие склады не вместили груз, используются пустые контейнеры **на той же конструкции, где есть доступный склад с образцом нужной категории**. Среди пустых также приоритет у более вместительного. После первого успешного переноса такой контейнер закрепляется за категорией до конца прохода; затем назначение определяется по содержимому. Смешанные контейнеры не становятся получателями. Если места нет, остаток сохраняется у источника.

Внутри одной конструкции правильно отсортированные запасы не перекладываются между складами. Пустой контейнер без доступного склада-образца автоматически не заполняется.

## Корабль и база

Между разными конструкциями разрешён только перенос с подвижной конструкции на статическую базу. База не отправляет груз на корабль, два корабля и две отдельные базы не перетягивают запасы друг у друга. На корабле источником может быть и контейнер только с одной категорией: например, полный груз руды выгружается в рудный склад базы.

База определяется по сохранённому типу конструкции Static в физике игры, а не по скорости или включённому стояночному тормозу. Подвижная космическая база не распознаётся как статическая; автоматическая выгрузка между двумя подвижными конструкциями отключена. В пределах каждой из них сортировка работает.

Чтобы оставить резерв на корабле или защитить любой контейнер, добавьте `[NoSort]` либо `[Не сортировать]` в название. Исключение действует на отправку, приём и использование контейнера как образца.

Конвейерные пути и фильтры проверяются для конкретного предмета. Участвуют только функциональные ванильные грузовые контейнеры текущего владельца. Рюкзак, производство и чужие контейнеры не участвуют. Поддерживается локальный мир с серверной симуляцией внутри процесса; удалённые серверы не поддерживаются.

## Установка обновления

1. Закройте игру.
2. Распакуйте папку AutoSorter из архива в `D:\SE2Mods\AutoSorter` с заменой файлов. Если меняли AutoSorter.json, сохраните свою копию: новые обязательные настройки не добавлены.
3. Сохраните существующие параметры запуска Steam. Для отдельного запуска AutoSorter: `"-plugins:D:\SE2Mods\AutoSorter\AutoSorter.dll"`. Если используется BuildPlanner, оставьте его в существующем списке плагинов.
4. Загрузите копию мира и выполните проверки ниже. Версию видно в AutoSorter.log.

## Проверка в игре

- База: полный маленький склад руды с образцом, большой пустой контейнер и смешанный источник. Руда должна перейти в большой пустой контейнер, суммарное количество сохраниться.
- Два назначенных склада разных размеров: сначала используется более вместительный; после заполнения — следующий, затем пустые резервные.
- Подстыкуйте корабль с рудой к базе с рудой и смешанным грузом. Запасы базы не должны уходить на корабль; руда корабля должна выгружаться на базу при наличии места.
- Повторите с двумя кораблями, с `[NoSort]`, односторонним фильтром, разорванным конвейером и полностью заполненной базой.
- Проверьте два вида категорий и один пустой контейнер: он должен принять только одну категорию.

## Настройки и сборка

AutoSorter.json читается при запуске. Enabled включает сортировку; IntervalSeconds задаёт интервал (по умолчанию 2 секунды); MaxTransferAttempts и MaxItemChecks ограничивают работу за проход. SoftTimeBudgetMs — мягкий бюджет маршрутизации, не жёсткий предел сканирования всего мира. DryRun выводит кандидатов в лог без переноса; это не точный прогноз вместимости.

```powershell
dotnet build AutoSorter.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\SpaceEngineers2\Game2"
dotnet run --project tests/AutoSorter.Tests.csproj -c Release
```

Исключение отключает сортировку до перезагрузки мира и записывается в AutoSorter.log. Плагин не добавляет блоков и не требует конвертации сохранений. Уже сохранённые перемещения остаются обычной частью мира.

Ориентир загрузки плагина — BuildPlanner от Vito Pistelli (MIT). Лицензии сохранены в пакете; игровые DLL не распространяются.


## Защита инструментов при Alt + ПКМ (0.2.4)

Защищена штатная быстрая выгрузка при наведении на контейнер с закрытым инвентарём. Игра использует список EssentialItems, который может не содержать модовые инструменты. AutoSorter дополнительно исключает зарегистрированные ручные инструменты и оружие, включая AreaTools, только на время этой массовой операции. Обычный ручной перенос предмета через инвентарь остаётся доступным. Файлы игры и мода не меняются. При Enabled=false или DryRun=true дополнительная защита выключена. Alt+N BuildPlanner — другая команда, для неё нужен BuildPlanner с собственным исправлением защиты инструментов.
